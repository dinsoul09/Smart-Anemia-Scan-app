# Демо-режим для защиты

Всё новое лежит в `src/demo/` и ничего в существующих файлах не меняет.
Три правки нужно внести руками — они ниже.

## 1. Открыть экран (обязательно)

`App.js`, рядом с остальными импортами:

```js
import DemoScreen from './src/demo/DemoScreen';
```

и одна ветка в разметке, до проверки авторизации — чтобы демо работало без логина:

```js
if (activeScreen === 'demo') {
  return <DemoScreen onGoBack={() => setActiveScreen('signIn')} />;
}
```

Запускать так: в `useState('signIn')` временно поставить `'demo'` — приложение сразу
открывается на демо-экране. Для защиты этого достаточно, кнопку в меню можно не делать.

## 2. Адрес API

`src/demo/config.ts`, константа `API_BASE`. Для показа с ноутбука — `http://localhost:5000`
(порт смотрите в выводе `dotnet run`). Демо-экран ходит напрямую этим адресом и не зависит
от `src/api/apiClient.ts`.

Отдельно: в рабочем коде `src/api/anemiaApi.ts` запрос идёт голым `axios.post('/Analysis/...')`
без базового адреса — на вебе он уйдёт на origin страницы и вернёт 404. Для обычного
сканирования это стоит починить (использовать `apiClient`), но демо-экран это не затрагивает.

## 3. Бэкенд без логина

`AnalysisController` помечен `[Authorize]`, значит нужны Mongo и токен. Для показа проще
завести ветку `demo` и повесить `[AllowAnonymous]` на метод предсказания, а также разрешить
CORS для `http://localhost:8081` (иначе браузер молча заблокирует запрос).

Если оставляете облачный API — нужен интернет и живой сервер, поэтому обязательно прогоните
демо заранее: после первого удачного ответа он сохраняется, и при потере сети экран покажет
сохранённое значение с пометкой «офлайн».

## Что показывает экран

- Шесть записей CP-AnemiC с известным анализом крови, от 3,1 до 15,0 г/дл.
  Тап — отправка в модель, рядом лабораторное значение и ошибка.
- Переключатель калибровки места съёмки (виден, если модель возвращает число Hb).
- Пара Image_201 / Image_289: одно и то же изображение с хешем `01b0ad7991a9`
  и двумя разными лабораторными значениями — 10,4 и 3,3 г/дл.
- Подпись о том, на каких данных обучена модель, и дисклеймер «скрининг, не диагноз».
